# PLAN — 배속 모드 (트랙 설정) ✅ 완료 0.3.94 (2026-10-03)

## 목표
트랙 설정에서 배속(예: 0.75·1·1.25·1.5)을 고르면 그 패드가 그 빠르기로 나간다. 값 없음 = 1배(지금 그대로).

## 끝 기준
1. 트랙 설정에서 배속을 바꾸면 ▶ 미리듣기·패드 재생이 그 빠르기로 들린다(짧은 효과음·긴 곡 둘 다).
2. 배속 중에도 진행 막대·남은 시간·반복 멈춤·큐 "끝나면 저절로"가 맞게 끝난다.
3. 내보내기→가져오기 로그 `설정 담음 … 전부 같음`, `설정 비교 … 전부 같음`.

## 정한 것 (소유자 2026-10-03)
- 음정 유지 → 긴 곡은 배속이면 A(<audio> preservesPitch)로. 효과음은 음정 같이 바뀜(한계 알림).
- 막대(50~200%) + 단계 단추(0.75·1·1.25·1.5). 막대는 50·75·90·100·110·125·150·175·200 근처(±3)에 붙음.

## 남은 것
- 일괄 수정 배속 — 0.3.95에 넣음.

## 만드는 곳
- 저장: `S.pads[id].rate` (패드 안 → 내보내기·가져오기 저절로). zip 잘라 담기(cut0)와 무관(시각이 아니라 배율).
- 소리 길 3갈래(engine.js):
  - 짧은 효과음(메모리): `playbackRate` — 음정 같이 바뀜(유지 불가)
  - 긴 곡 A(Audio 태그): `playbackRate` + `preservesPitch` — 음정 유지 가능
  - 긴 곡 D(조금씩 풀기): 조각마다 `playbackRate`, 예약 시각을 배율로 나눔 — 음정 같이 바뀜. **음정 유지하려면 배속 패드는 A 길로 보낸다.**
- 시간 계산(app.js): 화면 시간 = 구간 길이 ÷ 배속. `playLen`·`segLen`·진행 위치·`loopStop` 타이머·페이드 초는 "실제 초" 그대로.
- 큐(cue.js): 자동 다음 = 실제 끝난 시각 기준이면 수정 없음, 길이 계산 쓰면 ÷배속.
