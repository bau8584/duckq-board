## 물음
트랙 추가할 때 유튜브 링크를 붙이면 바로 음원을 뽑아 넣을 수 있나?

## 판단 (Claude)
| | 내용 |
|---|---|
| 아이패드 앱만으로 | **불가.** 유튜브는 음원 파일을 직접 주지 않고, 다른 사이트(우리 앱)가 가져가는 것도 막는다(브라우저 보안). |
| PC 상자(duckq 도커)를 거치면 | **기술적으론 가능.** 상자에 `yt-dlp`를 넣고 "링크 → m4a 뽑기 → 앱이 받아 저장". 작업량 반나절~하루. |
| 걸리는 것 ① 약관 | 유튜브 이용약관은 허락 없는 내려받기를 금지. 도구 자체가 약관 위반 쪽. |
| 걸리는 것 ② 저작권 | 학교 공연·수업 사용이어도 음원 복제는 회색지대. **나눔(인디스쿨·덕구랩) 버전에 넣으면 기능을 퍼뜨리는 셈** → 넣으면 안 됨. |
| 걸리는 것 ③ 운영 | PC가 켜져 있어야 함, yt-dlp는 유튜브가 바뀔 때마다 자주 고장 → **정기 업데이트 의무**(재미가 의무 되면 안 된다 원칙). |
| 걸리는 것 ④ 관리자 손 | 링크 붙이기는 편하지만 실패(막힘·지역 제한) 때 이유 설명이 어려움. |

## 후보
1. **안 만든다 + 대안 안내 (추천)** — 아이패드 "파일" 앱·에어드롭으로 넣기 안내를 [?]에. 무료로 내려받기 허용된 음원(유튜브 오디오 보관함, 공유마당 등) 목록 링크.
2. 소유자 개인 PC 상자에서만 쓰는 비공개 기능 — 나눔 버전엔 스위치로 숨김. 약관 위험은 소유자 판단.
3. 링크로 "파일 찾기 도우미"만 — 제목만 읽어 트랙 이름을 채워 주고, 파일은 사용자가 넣음.
