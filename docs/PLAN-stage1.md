## 1. 0단계에서 확인된 전제
- **메모리는 넉넉함.** 소리 데이터 = 효과음(통째로 풀어 둠) + 긴 곡 D(곡당 최대 1.8MB, 122분 mp3·224MB wav도 같음). 극단 실제 판(효과음 20 × 5초 + 긴 곡 3 동시)으로 잡아도 **50MB 안팎** — 경고선 300MB의 1/6, T5에선 900MB까지 안 튕김(iPad Pro 11"). 브라우저 자체 사용량은 빠진 숫자.
- 긴 곡은 **D(직접 풀기)**, `<audio>`는 D 곡에 만들지 않는다(옆에 있기만 해도 소리가 튐).
