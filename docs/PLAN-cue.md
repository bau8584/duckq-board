- ■ 끄기 기본 = 패드를 다시 눌러 끌 때와 같은 페이드아웃. 옛 "◣ N초 끄기"는 "■ 끄기 · 따로 N초"로 저절로 옮김.
- 담기에서 켜 둔 소리를 또 누르면 ■ 끄기로 담김(패드 누르는 손 그대로). 담기 전 동작 고르기는 뺌.
- 볼륨 따로는 그 소리가 끝나면 트랙 볼륨으로 돌아옴.

## 0.3.47 쓰기 쉽게 (2026-09-29, 소유자 연극 연습 전)
- 연극식 번호: GO로 나가는 줄만 큐 1·2·3, 따라 나가는 줄은 ↳ + "앞 줄 소리가 끝나면/앞 줄과 동시에" 글로.
- 줄마다 두 줄: 소리 이름 / 상태(다음 차례 — GO · ♪ 울리는 중 · N초 뒤 나감 · 메모). 오른쪽에 동작(▶ 재생 · ◣ 3초 끄기 · ■ 끄기 · ↓ 1/4로).
- 옮기기: 줄 누름 = 다음 차례, 아래 ⤒ 처음 · ▲ 이전 · ▼ 다음, 페달·키보드 ←/↑/PageUp = 이전. 지나간 줄은 흐리게.
- 고치기: ⋯ → "언제 나가요? / 무엇을 해요? / 어떤 소리? / 기다렸다가 / 메모 / 정한 시각" + ▲위로 ▼아래로 복제 지우기 닫기. (칩 돌리기·번호 끌기는 뺌 — 뜻이 안 보였음)
- 담기 때 동작 미리 고르기(▶ 재생 / ◣ 줄이며 끄기 / ■ 끄기). 비었을 때·? 단추에 5줄 사용법.
- 글자 쓰는 중엔 목록을 다시 그리지 않음(소리 끝나도 입력 칸 유지).

## 만든 것 (0.3.42 — 0.3.45에서 패드별 칸은 없앰, 큐보드로 대신)
- 새 파일 cue.js·cue.css에 전부. 기존 파일엔 "Cue가 켜졌을 때만" 부르는 줄 6개(패드 누름·패드 표시·패드 설정·설정 스위치·내보내기·가져오기).
- 패드 칸: 다음(패드/랜덤) · 언제(끝나면/동시에) · 늦게 시작 · 넘기기 · 낮추기 · 시각 · 메모. GO 단추(조작부 맨 앞) + 페달·키보드.
- 안전: 대기 중 다시 누름=취소, 전체정지·◣=대기 취소, 고리 막음, GO 연타 0.35초, 손으로 끈 패드는 안 이어짐.
- PC 자동 시험 통과: 끔=영향 없음(값 있어도), 이어·늦게·함께·GO·넘기기·낮추기·랜덤·시각·내보내기 번호 변환.

## 아이패드 시험 (로그로 판정, 0.3.45)
큐 켜기 → [+ 담기] 패드 4개 → 칩으로 끝나면·같이·페이드 → GO 연속 → 기다림 넣고 ■로 취소 → 접기/펼치기 → 공연 모드 → 큐 끄기 후 패드 누름. 로그: `큐 담음`·`GO 큐 n/N`·`큐 n 재생`·`큐 대기 N개 취소`, 끈 뒤엔 `큐` 줄 없음.

## 버린 방법
- 담기 때 목록 앞 줄로 켜기/끄기 짐작(0.3.49~0.3.65): 켜야 할 줄이 끄기로 담김 → 지금 울리는 소리만 끄기.
- 끼우면 저절로 2-1 번호(0.3.59): 갑자기 붙어 놀람 → 자동 번호 + 줄마다 [하위 번호로].
- 큐시트를 글(.txt)로 만들어 고친 글을 다시 읽기: 고치면 읽기 오류 → 사람용(PDF)과 옮기기(zip)를 나눔.
- 장면을 큐 목록의 따로 된 항목으로 넣기: GO·번호·내보내기 모든 곳이 '소리 없는 줄'을 알아야 함 → 큐 줄의 scene 값으로.
- 패드 설정 창에서 패드마다 큐 칸(다음·언제·기다림…) 고르기(0.3.42): 하나하나 창을 열어야 해서 느림 → 큐보드에서 담고 칩으로.
- 줄의 칩을 눌러 값 돌리기·번호 꾹 끌어 순서(0.3.45): 무엇이 무엇인지 모름 → 글로 풀어 쓴 줄 + ⋯ 질문형 편집 + ▲▼.
- 보드 순서 = GO 순서: 패드 배치와 공연 순서가 서로 방해 → 큐 목록 따로.
- 엔진 'play' 이벤트로 '동시에'를 거는 법: 막대 끌어 위치 옮기기도 play를 불러 다시 울림 → 누름·GO 때만 거는 쪽으로.
- 손으로 끈 것/곡 끝을 엔진 이유(faded)로만 가르는 법: 솔로·◣로 꺼도 같은 이유 → 손으로 끈 패드를 따로 기억.
