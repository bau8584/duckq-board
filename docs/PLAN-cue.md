# PLAN — 큐 기능 (2026-09-30 · 0.3.49까지 완료, 다음 묶음 ①~⑨ 결정됨 — 새 세션에서 만들기)

## 왜
소유자 요청: 트랙 자동 연결 재생, N초 뒤 자동 재생, 트랙 그룹 등 큐 기능. 실용성 순으로.

## 후보 (실용성 순)
1순위: 이어 재생(A 끝 → B) · 늦게 시작(누르고 N초 뒤) · 함께 재생(그룹) · GO 단추(순서대로 다음)
2순위: 겹쳐 넘기기(B 누르면 A 페이드아웃) · 소리 낮추기(효과음 때 배경 작게) · 큐 메모
3순위(증거 생기면): 랜덤 · 시각 예약 · 외부 페달/키보드

## 설계 한 줄
패드마다 "다음 패드 · 대기 초 · (동시에/끝나면)" 칸 → 1순위 4개가 한 규칙으로 나옴. 옵션을 따로 늘리지 않는다.

## 정할 것 (소유자 답 기다리는 중)
1. 첫 묶음: ①이어+늦게 ②+GO(추천) ③+그룹
2. 연결 표시: 화살표 / 패드 구석 "→5" 번호(추천)
3. 연출님께 먼저 물어볼지(추천: 예 — 옵션 기준 ①현장 요구)

## 정해진 것
- 2026-09-29: 큐 기능은 **설정에서 켰을 때만 보인다**(끄면 칸·표시·GO 전부 숨김 = 지금 화면 그대로).
- 만들기보다 총 계획 확정이 먼저.
- 2026-09-29 (2차): 패드 길게 눌러 큐 넣기는 불편 → **C·나·①**로 다시 만든다.
  C = 왼쪽 큐 목록(공연 중 보기·GO) + 설정 [큐] 칸(한꺼번에 손보기) / 나 = 큐 목록을 보드 순서와 따로(같은 소리 두 번 가능) / ① = 목록엔 번호·이름·이음·기다림만, 나머지는 줄을 누르면 펼침.
  참고: QLab식 큐 목록(대기 줄 강조 → GO → 다음 줄로).
  화면: 오른쪽(패드와 MASTER 사이), 펼침 280px/접힘 44px 둘 다. GO는 아래 조작부.
- 2026-09-29 (3차): 큐는 **큐보드에서 넣는다**. [+ 담기] → 패드를 순서대로 누르면 큐가 쌓임(소리 안 남). 줄 = 이음 칩(GO→끝나면→같이, 누를 때마다 넘김) + 소리 + 동작 칩(누르면 메뉴: 재생·끄기·페이드 1/3/5/10초·낮추기 1/2·1/4·1/10·원래 크기). 이름 누름 = 펼쳐 소리·기다림·시각·메모·복제·지우기. 번호 누름 = 대기로, 꾹 끌기 = 순서.
  큐 목록은 보드마다 하나(board.cues). 설정 [큐] 칸 = 모든 줄 펼친 채 + 모두 GO로·모두 지우기.

## 지킬 것
옵션 기준(UX-REVIEW §6): 현장 요구 또는 동작-화면 괴리일 때만. 기존 패드는 "값 없음 = 지금 동작". 공연 모드에서 잘못 눌러도 안전하게.

## 다음 묶음 (2026-09-30 소유자 승인, 새 세션에서) — 만드는 순서
근거: 어제 로그 — 보드 트랙 37개(목록 30~40줄 예상), 연습 중 GO→줄 눌러 되돌리기→GO 반복, 담은 큐를 끝에서 위로 옮김(큐 4 → 2).
1. ③ 담기 = "다음 차례" 줄 **뒤에 끼워 넣기**(끝에 붙이지 않음) · ④ **↶ 방금 GO 취소**(몇 초 안: 방금 켠 소리 끄기 + 다음 차례 되돌림)
2. ① 재생 큐에 **"꺼질 때"**: 끝까지(기본 = 지금 동작) / 다음 GO 때 / 다음 소리가 나올 때 / 큐 N이 나갈 때 / 직접 끄기 큐로. 꺼질 때 페이드 = 트랙대로 기본. "다음 소리"는 음악·효과음 구분 없이(효과음 때 꺼지는 문제가 실제로 생기면 그때 구분).
   줄 모양: `1 하우스 음악 ▶ 재생 · 꺼짐: 다음 소리`
3. ② **장면 제목 줄**("1막 2장 — 병원"): 목록 사이 머리 줄, 접힌 띠에서도 장면으로 건너뛰기.
4. ⑦ **고정 번호 2-1 방식**: 번호를 담을 때 정해 저장(대본 번호가 안 밀림). N 뒤에 끼우면 N-1, N-2… 2-1과 2-2 사이는 2-1-1(드묾). 설정 [큐] 칸에 [번호 새로 매기기](대본 확정 전 정리). ↳ 줄은 번호 없음 그대로. (2.5 소수점 안은 버림: 시간 초와 헷갈림)
5. ⑤ 못 트는 줄(파일 없음 등) ⚠ + 공연 모드 켤 때 "⚠ N개" 알림 · ⑥ 울리는 줄에 남은 시간(♪ 12:30 남음) · ⑨ 아래 "다음" 칸에 그다음 한 줄 미리 보기
6. ⑧ **큐시트**: 한 장만 읽어도 오퍼가 공연 흐름을 아는 글(장면 머리 · 번호 · 신호(메모) · 소리 · 켜짐/꺼짐·페이드) + 다른 기기 DuckQ가 읽어 들임(소리 이름으로 패드 연결). 예:
   ```
   ■ 1막 1장 — 성벽
    1    "누구냐!" 뒤   하우스 음악  ▶ 켬 · 꺼짐: 다음 소리 · 아웃 3초
    2-1  (앞과 동시에)  바람         ▶ 켬 · 꺼짐: 큐 4
   ```
끝 기준 후보: ① 40줄 공연을 장면으로 건너뛰며 GO로 끝까지 · ② 큐시트 한 장을 읽고 흐름을 말할 수 있다 · ③ 큐 끄면 전과 똑같다.

## 0.3.49 트랙대로가 기본 (2026-09-29, 연습 로그: 큐 ■ 끄기가 뚝 끊김 · 두 번 담으면 다시 재생)
- 트랙 = 소리의 기본값, 큐 = 언제·무엇을 + 다를 때만 따로. ▶ 재생: 페이드인·볼륨 [트랙대로]/따로, ■ 끄기: 페이드아웃 [트랙대로]/바로/N초. 트랙 값은 흐리게 보여 줌, 따로 정한 큐만 줄에 값이 굵게.
- ■ 끄기 기본 = 패드를 다시 눌러 끌 때와 같은 페이드아웃. 옛 "◣ N초 끄기"는 "■ 끄기 · 따로 N초"로 저절로 옮김.
- 담기에서 켜 둔 소리를 또 누르면 ■ 끄기로 담김(패드 누르는 손 그대로). 담기 전 동작 고르기는 뺌.
- 볼륨 따로는 그 소리가 끝나면 트랙 볼륨으로 돌아옴.

## 0.3.47 쓰기 쉽게 (2026-09-29, 소유자 연극 연습 전)
- 연극식 번호: GO로 나가는 줄만 큐 1·2·3, 따라 나가는 줄은 ↳ + "앞 줄 소리가 끝나면/앞 줄과 동시에" 글로.
- 줄마다 두 줄: 소리 이름 / 상태(다음 차례 — GO · ♪ 울리는 중 · N초 뒤 나감 · 메모). 오른쪽에 동작(▶ 재생 · ◣ 3초 끄기 · ■ 끄기 · ↓ 1/4로).
- 옮기기: 줄 누름 = 다음 차례, 아래 ⤒ 처음 · ▲ 이전 · ▼ 다음, 페달·키보드 ←/↑/PageUp = 이전. 지나간 줄은 흐리게.
- 고치기: ⋯ → "언제 나가요? / 무엇을 해요? / 어떤 소리? / 기다렸다가 / 메모 / 정한 시각" + ▲위로 ▼아래로 복제 지우기 닫기. (칩 돌리기·번호 끌기는 뺌 — 뜻이 안 보였음)
- 담기 때 동작 미리 고르기(▶ 재생 / ◣ 줄이며 끄기 / ■ 끄기). 비었을 때·? 단추에 5줄 사용법.
- 글자 쓰는 중엔 목록을 다시 그리지 않음(소리 끝나도 입력 칸 유지).

## 만든 것 (0.3.42 — 0.3.45에서 패드별 칸은 없앰, 큐보드로 대신)
- 새 파일 cue.js·cue.css에 전부. 기존 파일엔 "Cue가 켜졌을 때만" 부르는 줄 6개(패드 누름·패드 표시·패드 설정·설정 스위치·내보내기·가져오기).
- 패드 칸: 다음(패드/랜덤) · 언제(끝나면/동시에) · 늦게 시작 · 넘기기 · 낮추기 · 시각 · 메모. GO 단추(조작부 맨 앞) + 페달·키보드.
- 안전: 대기 중 다시 누름=취소, 전체정지·◣=대기 취소, 고리 막음, GO 연타 0.35초, 손으로 끈 패드는 안 이어짐.
- PC 자동 시험 통과: 끔=영향 없음(값 있어도), 이어·늦게·함께·GO·넘기기·낮추기·랜덤·시각·내보내기 번호 변환.

## 아이패드 시험 (로그로 판정, 0.3.45)
큐 켜기 → [+ 담기] 패드 4개 → 칩으로 끝나면·같이·페이드 → GO 연속 → 기다림 넣고 ■로 취소 → 접기/펼치기 → 공연 모드 → 큐 끄기 후 패드 누름. 로그: `큐 담음`·`GO 큐 n/N`·`큐 n 재생`·`큐 대기 N개 취소`, 끈 뒤엔 `큐` 줄 없음.

## 버린 방법
- 패드 설정 창에서 패드마다 큐 칸(다음·언제·기다림…) 고르기(0.3.42): 하나하나 창을 열어야 해서 느림 → 큐보드에서 담고 칩으로.
- 줄의 칩을 눌러 값 돌리기·번호 꾹 끌어 순서(0.3.45): 무엇이 무엇인지 모름 → 글로 풀어 쓴 줄 + ⋯ 질문형 편집 + ▲▼.
- 보드 순서 = GO 순서: 패드 배치와 공연 순서가 서로 방해 → 큐 목록 따로.
- 엔진 'play' 이벤트로 '동시에'를 거는 법: 막대 끌어 위치 옮기기도 play를 불러 다시 울림 → 누름·GO 때만 거는 쪽으로.
- 손으로 끈 것/곡 끝을 엔진 이유(faded)로만 가르는 법: 솔로·◣로 꺼도 같은 이유 → 손으로 끈 패드를 따로 기억.
