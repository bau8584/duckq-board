# PLAN — 리허설 기록 + 조건 큐 (2026-10-06 시작)

로드맵 3번. 받아쓰기 없음, 인터넷 없이 됨. 마이크 소리는 **크기 숫자만** 기기 안에서 계산하고, 소리 자체는 녹음·저장·전송하지 않는다.

## 단계
- **① 기록 (이번 세션)** — 리허설 때 GO 누른 순간을 기억하고 리허설 보고로 보여 준다.
  - 큐마다: 앞 큐에서 +N초 · 직전 몇 초에 박수(큰 소리 뭉치)가 있었나 · 직전 침묵이 몇 초였나 · 소리 크기 흐름(작은 막대).
- ② 알려 주기 (나중) — 기록을 바탕으로 "지금쯤이에요"를 GO 단추 깜빡임으로. 누르는 건 사람.
- ③ 자동 GO (나중) — 큐별로 고른 것만 조건(박수 끝·침묵 N초·앞 큐 +N초)이 맞으면 저절로 GO. 기본은 꺼짐.

## 끝 기준 (①) — 소유자가 화면으로 확인
1. 큐 탭에서 [리허설 시작] → 마이크 허용 → GO를 몇 번 누르고 [끝] → **리허설 보고**에 큐마다 "+N초 · 박수/침묵" 줄이 보인다. 와이파이를 끈 상태에서도 된다.
2. 리허설 중이 아닐 때는 마이크가 켜지지 않고, 화면·GO 동작이 전과 똑같다.
3. 내보내기→가져오기 로그가 `설정 담음 … 전부 같음`, `설정 비교 … 전부 같음`.

## 정한 것 (2026-10-06 소유자)
- 기록 자리 = **보드 안**(큐마다 `c.rh`) → zip에 같이 감. 숫자만이라 목소리 안 나감.
- **최근 3번**만. 4번째 시작 때 가장 옛것 지울지 물음.
- [● 리허설] / [보고] 단추 = **큐보드 위쪽**. 켜진 동안 빨간 '● 끝'.

## ① 상태 — 0.3.108 (dev)
- 완료: 기록·보고·내보내기/가져오기 확인(PC, 가짜 마이크). 남은 확인: 아이패드 실제 마이크로 한 번(박수 잡히는지, 에코 제거로 앱 소리가 빠지는지).
- 판정 기준(바꿀 수 있음): 바닥 = 지난 30초 아래 10% · 큰 소리 = 바닥+18dB가 0.3초 넘게 · 조용 = 바닥+6dB 아래.

## ② 알려 주기 — 0.3.112 (dev)
- 설정 → 큐 탭 아래 **'리허설대로 알려 주기'** = 보드마다(`b.rehHint`, 값 없음 = 꺼짐, zip에 저절로 담김). 기준 = **가장 최근 리허설**(소유자: 그대로 연습하니까).
- 다음 큐의 기록으로 하나만 봄: 박수 끝나고 10초 안에 GO → '큰 소리 끝나고 N초' / 아니면 조용 2초 넘게 → '조용 N초' / 아니면 '앞 큐 +N초 − 2초'. 박수·조용은 리허설 간격의 절반 전엔 안 봄(이른 박수에 속지 않게).
- 깜빡임 = GO 노란 깜빡(움직임 줄이기 켜면 노랑 고정). GO 누르면 꺼짐. 로그에 `알려 주기 큐 N: … (지금 +N초)`.
- **마이크**: 박수·조용 기록이 있는 보드에서만, 공연 중 첫 GO 때 한 번 켜고 큐 끝·설정 끔·보드 바꿈까지 유지(껐다 켜면 아이패드가 다시 물을 수 있어서 — 소유자 걱정). 리허설 기록 시작하면 넘겨받음.
- 확인됨(PC): 시간 기준 깜빡임·끄면 안 깜빡임·내보내기→가져오기 `전부 같음` 두 줄. **남은 확인: 아이패드 실제 마이크**(아래 판정 숫자와 같이).
- 판정 숫자 맞추기: GO 로그에 `(바닥 -NdB · 직전 10초 최고 바닥+NdB)` 찍음. 박수 → 조용 → 음악만 순서로 GO해 보고 맞춤.

## ③ 큐별 자동 GO — 할 일
- 큐 ⋯ 편집에 '자동 GO: 박수 끝나고 N초 / 조용 N초 / 앞 큐 +N초' 중 고름(값 없음 = 사람이 누름). 기록에서 기본값 제안.
- 안전장치: 자동으로 나가기 2초 전 GO에 카운트다운, 그 사이 ▲로 취소. 공연 중 마이크는 이 기능 켠 큐가 다음일 때만.

## 버린 방법
- 받아쓰기(대사)로 신호 잡기 — 4번 '대사 인식'으로 따로.
- 리허설 소리 녹음 파일 남기기 — 크기 숫자만으로 ①~③ 다 됨. 학생 목소리를 남길 이유 없음.
