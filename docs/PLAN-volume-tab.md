# PLAN — 설정에 [볼륨] 칸 (2026-09-29 요청, 시작 전)

## 왜
소유자 요청: 설정 [일반][페이드] 옆에 [볼륨] 칸. 페이드 칸처럼 트랙(패드)별 볼륨을 한곳에서 관리.

## 근거
- 페이드 칸 = app.js `fadeTab()` — 범위 고르기(모든 보드 / 보드별 칩) + 패드 목록. 이 모양을 그대로 따라 만든다(UX-REVIEW §5 "같은 개념은 같은 모양").
- 패드 볼륨 = `p.vol`(0~3, 300%는 현장 요구로 유지), 소리 반영 = Engine에 볼륨 적용하는 기존 패드 설정 경로 재사용.

## 정할 것 (새 세션 첫 답)
1. 한 줄 모양: 막대(슬라이더) / 숫자 +− / 둘 다
2. 여러 패드 한 번에(선택 → 같은 값, 또는 전부 +10%)
3. 재생 중 바꾸면 바로 들리게 할지

## 지킬 것
- 기존 볼륨 값 안 바뀜. [취소]로 되돌리기(기존 시트 스냅샷).
- 커밋은 고친 파일만, dev, ?v= 올리기.
