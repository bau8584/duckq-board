# PLAN — 보드에서 바로 녹음 (2026-10-03)

## 하려는 것
보드(패드)에서 바로 대사를 녹음해 그 패드 소리로 쓴다. 녹음할 때 잡음을 줄인다.

## 끝 기준 (안)
1. 아이패드에서 빈 패드 → 녹음 → 멈춤 → 그 패드를 누르면 방금 녹음이 나온다.
2. 녹음본이 내보내기 zip에 담기고, 가져오면 그대로 들어온다.
3. 공연 중(GO 재생)에 녹음 단추가 실수로 눌리지 않는다(편집 때만 보임).

## 방법 (추천)
- 브라우저 마이크 기능에 이미 들어 있는 **잡음 억제·에코 제거**를 켜고 녹음한다(따로 받을 것 없음, 아이패드 사파리 지원 확인 필요).
- 녹음본은 기존 음원과 똑같이 패드 파일로 저장 → 내보내기·가져오기 규칙(CLAUDE.md) 자동 적용.
- 앞뒤 빈 소리는 기존 트림으로 다듬는다.

## 버린 방법
- 기존 음원 파일 잡음 제거(ffmpeg 필터 A / AI RNNoise B): 관리자 음성 5개로 시험 → 소유자가 원본과 차이를 못 느낌. 기각.
  - 시험 중 알게 된 것: 원본 mp3 앞부분에 "Header missing" 경고(작은 손상), mp3 인코더가 AI 처리본에서 멈춤 → wav/aac로 우회했음.
- 앱 안에 AI 잡음 엔진 넣기: 위 시험 결과로 효과 대비 무게가 큼. 브라우저 기본 억제부터 해 보고 부족할 때만 다시 검토.

## 정한 것 (2026-10-03 소유자)
- 단추 자리: **＋ 추가 → [파일 넣기 / 녹음하기]**. 잠금이면 ＋ 추가가 꺼지니 녹음도 막힘.
- 녹음 중 표시: **B안 — 화면을 덮는 녹음 창**(빨간 점·시간·소리 크기 막대·멈춤·취소). A안(패드에 빨간 점)은 녹음 중 다른 패드를 누르면 그 소리가 녹음에 섞여서 버림.
- 앱을 벗어나면(홈 버튼) 거기까지 저장하고 알림.
- 녹음본은 WAV로 바꿔 저장(크롬 webm은 길이가 안 잡혀서). 30초 ≈ 3MB.
