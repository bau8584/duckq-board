## 결정 (2026-10-06, 소유자)
- 앱 파일은 하나. 앱이 켤 때 주소를 보고 판단(q.deokgu.com·PC 8765만 실험실). 공개 주소에선 설정 칸도 숨김(A안), 서버에 묻지도 않음.
- 일반 설정에 '음원 서랍' 켜기/끄기(`S.settings.drawer`, 값 없음 = 끔 → 내보내기·가져오기에 저절로 담김).
- 서버 코드는 duckq-board 안(`test/log-server.py`의 /drawer/). 파일은 `C:\덕구box\음원서랍`.

## 끝 기준 (1차: 음원 서랍)
1. 아이패드 A에서 음원을 서랍에 올리면, 아이패드 B의 서랍 목록에 보인다.
2. 서랍에서 고르면 패드가 생기고 소리가 난다.
3. github.io(공개 주소)에서 열면 서랍 단추가 안 보인다.

## 진행 (2026-10-06, 0.3.107)
