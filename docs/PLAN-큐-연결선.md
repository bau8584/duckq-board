# PLAN: 큐시트 연결선 (곡 생명선)

## 하려는 것 (2026-10-01 소유자 승인 — 후보 2)
- 큐 목록 왼쪽에 **곡(패드)마다 색 세로선**: ▶ 재생 줄에서 시작 → ◢ 볼륨 줄에 점 → ■ 끄기 줄(또는 '언제 꺼짐' 줄)에서 끝.
- 지금 줄을 지나가는 선 = 지금 나오는 곡. 안 끈 곡은 선이 끝까지 열림, 꺼진 곡을 또 끄면 이을 선 없음(경고 색).
- 화면 표시만. 큐 데이터·내보내기 설정은 안 바뀜.

## 버린 방법
- 엔트리식 감싸기(블록 안에 품기): 곡이 엇갈려 끝나면(A켜기·B켜기·A끄기·B끄기) 상자가 겹쳐 못 그림.
- 같은 색 표시만: "어디까지 켜져 있나"가 안 보임.

## 정할 것
- 칸 수 상한(예: 3칸, 넘치면 줄 끝 이름표).
- 색: 패드 색을 쓸지, 칸마다 고정 색을 쓸지.

## 참고
- 0.3.80에서 동작 단추를 오른쪽으로 옮겨 왼쪽(번호 앞)이 비어 있음 → 선 자리.
- 랜덤 소리 줄·하위(↳) 줄·구분 줄에서 선이 끊기지 않게.
