## B. 페이드 (끝 기준 2)
> 규칙: 페이드는 **그 곡에 켜 둔 것만** 걸린다. 페이드아웃을 켠 곡은 ① 끝까지 흘러가서 끝날 때 ② 재생 중 다시 눌러 끌 때, 둘 다 같은 초로 줄어든다.
> 0.3 전에 넣은 곡은 예전 기본값(아웃 켬·2초)이 그대로 남아 있다. 새로 넣는 곡만 기본 '끔'.

| # | 할 것 | 로그로 보는 것 |
|---|---|---|
| B1 ✅ | 설정 → [페이드] 칸 → 곡마다 켬/끔 스위치와 초가 제대로 보이는지 | 메모 |
| B2 | 짧은 곡 하나: 페이드 창에서 **아웃 켬** → 그 곡을 틀고 **손대지 않고 끝까지** 둠 → 끝부분이 뚝 끊기지 않고 서서히 작아지는지 ★ | `▶ … 아웃 N초` → `곡 끝` |
| B3 ✅ | 같은 곡을 틀고 **중간에 다시 탭** → 서서히 꺼지는지 | `◢ 페이드아웃 시작` → `페이드 끝` |
| B4 | 아웃 **끈** 곡을 끝까지 / 중간에 탭 → 둘 다 바로 멈추는지 | `▶ … 아웃 끔` → `곡 끝` / `바로 정지` |
| B5 | 설정 → [페이드]: 보드 칩으로 목록 바꾸기, 곡 몇 개 체크 → 인/아웃 칸에서 켬·끔과 시간 정하고 [선택 변경]은 체크한 곡만, [전체 변경]은 목록 전부 바뀌는지 → [되돌리기] | `페이드 한 번에 … (선택)` → `되돌리기` |
| B6 | 파일을 새로 하나 넣고 페이드 창에서 보기 → 인·아웃 둘 다 꺼져 있는지 | `▶ … 인 끔 · 아웃 끔` |
| B7 | 반복 켠 곡 + 아웃 켬 → 끝없이 돌고, 탭하면 서서히 꺼지는지 | `◢` |
