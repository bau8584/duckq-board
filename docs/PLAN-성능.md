# PLAN-성능 — 렉 원인 찾고 줄이기 (2026-10-12)

소유자: 노래가 많거나 설정이 복잡하면 렉. ① 최적화 ② 일반 사용자는 원인을 모름 ③ 무거운 기능 정리.

## 1단계 — 재기 (0.3.117, 완료)
- 최근 기록에 `느림: <일> <ms> · <크기>` (한 일이 50ms 넘음, 같은 일은 2초에 한 줄)
- `멈춤: <초> · 직전 일 <일>` (0.1초 시계가 0.15초 넘게 밀림. 화면 숨김 땐 안 잼)
- 켤 때 `가장 오래 걸린 소리: <이름> <초>`
- 재는 일: 저장 · 패드 판 다시 그리기 · 화면 전체 · 패드 전부 칠하기 · 큐 화면 그리기
- PC 시험(퓨어리스트 37곡, 42.8MB): 켜기 0.6~0.8초, 큐 화면 그리기 57ms 한 번. PC에선 렉 거의 없음 → **아이패드 실사용 기록이 필요**

## 2단계 — 고치기 (새 세션, 기록 보고)
후보(코드 읽기로 찾은 것, 재보기 전): 
1. 저장이 패드 누를 때마다 설정 전체 → 모아서 한 번에
2. 큐 화면이 대기 큐 있으면 0.2초마다 통째로 다시 그림 + 모든 패드 표시 다시 붙임
3. 켤 때 모든 보드 소리를 한 번에 메모리로(30초 이하 효과음) — 줄이려면 필요할 때 불러오기
4. 여러 곡 가져오기 때 곡마다 판 전체 다시 그림
5. 패드마다 소리 통로 2개 상시

## 버린 방법
- 재기 전에 짐작으로 고치기 (버그 규칙)
- 재생 목록 그리기(0.25초마다)를 재는 일에 넣기 → "직전 일"이 늘 그것으로 덮여 쓸모없어서 뺌
- 사용자 화면 안내(토스트)는 문구 미정이라 1단계에서 뺌
