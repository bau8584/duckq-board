## 종합 판정 (§3 규칙)

**아직 판정 불가 — T1은 재측정이 필요하고, T2~T5·T9는 미실시.** 웹으로 갈지는 T1 재측정 + T2~T5·T9 뒤에 hq 세션이 정한다.

**T1 체감 지연의 원인 후보**
1. **iPad Safari의 실제 출력 지연이 큼** — 브라우저가 0ms로 보고해 로그에 안 잡힘. 확인: 같은 기기에서 Soundboard Studio와 나란히 눌러 비교하거나, 폰 슬로모션으로 "손가락 닿음 → 소리" 간격 촬영.
2. **연타 때 같은 소리가 겹쳐 쌓임** — 전체 정지가 연타를 못 끊어 소리가 계속 이어졌고, 겹친 소리가 "버벅임"으로 들렸을 수 있음. 확인: 테스트 페이지에서 전체 정지가 연타까지 멈추게 고친 뒤 재시험.
3. **두 번 탭 확대가 입력을 먹음** — 확대 제스처로 인식된 탭은 소리가 안 나거나 늦게 남. 확인: 페이지 전체에 줌 방지를 넣고 재시험.
