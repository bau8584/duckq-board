**T1 체감 지연의 원인 후보**
1. **iPad Safari의 실제 출력 지연이 큼** — 브라우저가 0ms로 보고해 로그에 안 잡힘. 확인: 같은 기기에서 Soundboard Studio와 나란히 눌러 비교하거나, 폰 슬로모션으로 "손가락 닿음 → 소리" 간격 촬영.

3. **두 번 탭 확대가 입력을 먹음** — 확대 제스처로 인식된 탭은 소리가 안 나거나 늦게 남. 확인: 페이지 전체에 줌 방지를 넣고 재시험.
