# PLAN — MASTER 100%로 되돌리기 단추 (2026-09-30 요청, 시작 전)

## 왜
소유자 요청: 공연 중 MASTER를 만지다가 한 번에 100%로 돌아가고 싶다.

## 정할 것 (새 세션 첫 답)
1. 모양: MASTER 막대 숫자를 두 번 누르기 / 막대 옆에 ↺ 단추 / 막대를 길게 누르기
2. MASTER 키우기(1.5·2·3배)가 켜져 있을 때 "100" = 원래 소리 100%인가, 막대 맨 위인가
3. 공연 모드에서 잘못 눌리지 않게 막을지

## 근거
