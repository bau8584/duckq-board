# PLAN: GO 두 번 눌림 막기 + GO 버튼 키우기

## 왜 (2026-10-03 연극 연습 로그)
- GO가 1초 안에 두 번 눌려 다음 큐까지 나간 일이 3번: 12:22:42/43, 12:22:47 ×2(4번·5번 관리자), 14:01:12 ×2(큐 14·15, 본 리허설 중).
- 매번 일시정지·전체정지 → 한 큐 되돌려서 다시 했다.
- 소유자 요청: 막는 것과 함께 GO 버튼을 더 크게.

## 끝 기준
1. GO를 빠르게 두 번 눌러도 큐가 하나만 나간다(로그에 무시했다는 줄이 남는다).
2. GO 버튼이 지금보다 눈에 띄게 크고, 휴대폰·패드 화면에서 다른 칸을 가리지 않는다.
3. 일부러 연달아 누르는 경우(0.5초 넘게 띄움)는 지금처럼 바로 나간다.

## 방향
- 추천: GO 후 짧은 시간(0.5초 안팎) 두 번째 GO는 무시. 확인 창은 버림(관리자 손이 늘어남).
- 키보드·리모컨 GO도 같은 규칙인지 확인.
- 버튼 크기는 화면 캡처로 전/후 비교해 소유자가 고른다.
