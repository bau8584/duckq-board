# 홈 화면 추가 안내

## 결정 (2026-09-30 소유자)
- ① 웹 탭으로 열면 **매번** "▶ 시작" 창 안에 안내(이미 누르던 창이라 누를 일 안 늘어남). 홈 화면 앱이면 안 보임.
- 버림: 시작 화면 카드(A)·설정에만(B)·경고 띠(C)·"다시 보지 않기"(③) — 보드 날아가는 손해가 더 큼.

## 0.3.63 완료
- 아이폰·아이패드: 공유 → 홈 화면에 추가 글 / 맥 사파리: 파일 → Dock에 추가 / 크롬·엣지·안드로이드: [앱으로 설치] 버튼(브라우저가 허락할 때만 뜸).
- PC 창에서 안내 보임·시작 누르면 닫힘 확인.

## 남은 것
- 실기기 확인: 아이폰 사파리 탭 vs 홈 화면 앱, 안드로이드 크롬 설치 버튼.
