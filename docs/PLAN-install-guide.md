# 홈 화면 추가 안내 (새 세션 할 일)

## 왜
- 사파리 탭으로만 쓰면 7일 안 열면 저장된 보드가 지워질 수 있음. 홈 화면 앱은 안 지워짐.
- 아이패드: 홈 화면 앱은 사파리와 저장 공간이 따로. 아이콘을 지우면 그 안 보드도 지워질 수 있음 → 아이콘 바꾸려면 보드 파일 내보내기 먼저.

## 후보 (소유자 결정 전)
- A(추천) 사파리 탭으로 열었을 때만 시작 화면에 한 번 안내(공유 → 홈 화면에 추가 그림 + "여기에 담아야 안 지워져요"). 닫으면 다시 안 뜸. 홈 화면 앱에선 안 뜸.
- B 설정에만 안내 — 첫 사용자가 못 봄.
- C 탭으로 쓰는 동안 경고 띠 — 공연 화면을 가림.

## 조건 (2026-09-30 소유자)
- 아이패드·아이폰만이 아니라 **안드로이드 폰·태블릿, 노트북(크롬·엣지·사파리)**에서도 통해야 함. 기기마다 추가하는 법이 다름(안드로이드·PC 크롬은 설치 버튼을 띄울 수 있음, 아이폰·아이패드는 공유 메뉴로만).
