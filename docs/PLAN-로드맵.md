# PLAN — 다음 기능 로드맵 (2026-10-04)

각 묶음은 시작할 때 따로 `PLAN-<이름>.md`로 떼어 끝 기준을 정한다. 여기는 순서와 큰 그림만.

## 순서 (추천)
1. **실험실 서버** — 선생님 주소(q.deokgu.com/app/, dev)에서만 켜짐. 공개(GitHub main)엔 안 보임.
   - 음원 서랍: PC 서버에 음원을 올려 두고 어느 아이패드에서든 골라 패드로. 유튜브 뽑기(/yt)가 서랍으로 바로.
   - QR로 보드 넘기기: zip을 서버에 잠깐 올리고 QR로 받기(선생님 기기끼리만 — 다른 선생님은 로그인 문을 못 넘음).
2. **모바일(폰) 화면** — 아래 '모바일' 참고.
3. **리허설 기록 + 조건 큐 (소리 크기·시간·침묵)** — 받아쓰기 없이, 오프라인 가능.
   - 리허설 때 GO 누른 순간을 기억(앞 큐 +N초, 직전 박수·침묵).
   - 단계: ① 기록만(리허설 보고) → ② 알려 주기(GO 깜빡임, 누르는 건 사람 — 기본) → ③ 큐별로 고른 것만 자동 GO.
4. **대사 인식** — 집 PC 서버 Whisper로 받아쓰기(목소리가 PC 밖으로 안 나감). GO 직전 대사를 신호로. 1~2초 늦음 → '직전 대사' 기준. 인터넷 약하면 3번 조건만.
5. **리모컨 GO** — 폰으로 GO·정지. 1번 서버 길 위에.
6. 끼워 넣기(행사 일정에 맞춰): **목소리 효과**(녹음 창에서 마이크·전화·괴물·메아리), **보드 견본 3종**(학예회·운동회·졸업식, 한 번 만들고 끝 — 계속 채우는 의무 안 만듦).

## 모바일
- 지금: 아이패드 기준. 폰은 일부 넘침만 고쳐 둔 상태(0.3.97).
- 후보: A 폰 = 리모컨 전용 / B 폰 단독 소리판(세로 한 손: 큐 목록 + 큰 GO, 패드는 넘겨 보기) / C 앱스토어 앱 포장.
- 추천: **B를 같은 코드로(화면만 폰 맞춤)** → 그 화면에 리모컨 모드(A)를 얹음. C는 안 함(심사·연간 비용·업데이트 부담).

## 버린 것·확인한 것
- 비상 전체 페이드: 이미 있음(아래 ◣ 단추, 설정의 페이드 초). 후보에서 뺌.
- 큐 메모 크게: 화면 나누기 바꾸기가 아니라 GO 안 '다음 큐' 옆에 메모 띄우기 — 소유자 반응 미정, 보류.
- 받아쓰기를 아이패드 내장(사파리)으로: 길게 듣기가 끊기고 목소리가 애플 서버로 나갈 수 있어 2순위.
