# PLAN — 파일 볼륨 키우기 — 완료 2026-10-09 (app 0.3.115)

## 왜 (2026-10-09)
- 총소리 패드 볼륨을 300%·MASTER를 올려도 안 커짐. 원인: 원본이 이미 최대(0dB, 평균 -10dB)라서 100%를 넘기면 켜지는 리미터(engine.js, -3dB·20:1)가 키운 만큼 다시 눌러 버림.
- PC에서 ffmpeg로 "키운 뒤 넘치는 부분만 눌러 담기"(+18dB → 리미터 0.95)를 하니 평균 약 +3dB. 이걸 앱 안에서.

## 결정 (소유자)
- 이름: **파일 볼륨 키우기**
- 단계: 세 칸 **조금 / 많이 / 최대** 중 고르기 → 미리 듣기 → 확인하면 **새 패드**(원본 그대로)
- "최대"에는 "소리가 거칠어질 수 있어요" 한 줄.

## 어떻게
- "목소리 바꾸기"(app.js `VOICES`, OfflineAudioContext로 구워 WAV → 새 패드)와 같은 길을 쓴다. 효과 칸에 넣을지, 따로 버튼으로 둘지는 화면 보고 판단(관리자 손 최소).
- 처리: 게인(조금 +6 / 많이 +12 / 최대 +18dB 정도, 귀로 조정) → 빠른 리미터(천장 약 -0.5dB) → WAV.
- 새 패드는 vol 100%로. 이름 뒤에 단계 표시(예: "총소리 많이").

## 버린 방법
- 볼륨 최대치를 300% 이상으로 올리기: 리미터가 다시 눌러서 소용없음.
- 리미터 끄기: 찢어지는 소리 남.
- 슬라이더(dB 숫자): 현장에선 귀로 세 칸이 빠름.

## 끝 기준
1. 총소리 패드에서 "많이"를 골라 만든 새 패드가 원본보다 확실히 크게 들린다.
2. 원본 패드는 그대로다.
3. 내보내기→가져오기 로그 "전부 같음" 두 줄.
