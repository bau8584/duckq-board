# PLAN — 폰 화면 (로드맵 2번, B안)

시작 2026-10-06. 로드맵 추천 B: **폰 단독 소리판** — 세로 한 손, 큐 목록 + 큰 GO, 패드는 넘겨 보기.
같은 앱 코드에서 화면만 폰에 맞춘다. 나중에 리모컨 모드(로드맵 5번 A)를 이 화면에 얹는다.

## 지금 상태
- 아이패드 기준 화면: 위(탭·설정·잠금·편집·추가) / 가운데(패드 판 + 큐 칸 + 오른쪽 MASTER) / 아래(재생 목록 + 일시정지·정지·페이드).
- 폰은 0.3.97에서 넘치는 곳만 고침(폭 820px 이하 몇 줄).

## 끝 기준 (소유자가 화면으로 확인)
1. **폰 세로에서 한 손으로 공연 진행**: 큐 목록이 보이고, 엄지 닿는 곳의 큰 GO로 다음 큐가 나가고, 정지·페이드도 한 손으로 된다.
2. **패드도 폰에서 쓸 수 있다**: 패드는 옆으로 넘겨 보며 눌러 소리가 난다(글자 안 넘침).
3. **아이패드는 전과 똑같다**: 아이패드 가로·세로 캡처가 바꾸기 전과 같다.

## 지킬 것
- 폰 모양은 **폰 폭일 때만** 켜지게(아이패드 폭에선 한 줄도 안 바뀜).
- 새 설정이 생기면 `S.settings` 안에 + `SET_KO` 이름표(프로젝트 CLAUDE.md).
- 리모컨 모드(A)는 이번에 안 만듦 — 화면 자리만 남겨 둠.

## 결정 (소유자)
- 2026-10-06 화면 나누기: **아래 탭 두 장 [큐]/[패드]** (위아래 나누기·패드 서랍 버림 — 둘 다 작아지거나 패드가 숨음).
- 2026-10-06 남길 것: **전부 그대로**(편집·추가·녹음·설정까지 폰에서). 추천은 '공연만'이었음 — 공연 중 실수 걱정은 잠금으로 막는다.

## 한 일 (0.3.109)
- 폭 600px 이하에서만: 아래 탭 [큐]/[패드], 큐 탭 = 큐보드 늘 펼침(접기 단추 숨김)·GO 80px, 패드 탭 = 크게 2·보통 3·작게 4열, 오른쪽엔 MASTER만(상태 칸 숨김), 위 단추는 그림만, 아래 일시정지·정지·페이드는 폭 가득.
- 큐보드를 꺼 두면 탭 없이 패드만.
- 패드 '넘겨 보기'는 지금 **위아래로 밀기**(아이패드와 같은 방식). 옆으로 넘기는 페이지 방식은 편집 끌어 옮기기와 얽혀 따로 — 필요하면 다음 세션.
- 0.3.108 커밋(리허설 창)에 이 창의 app.js·cue.js·index.html 변경이 같이 담겼음 — 화면 규칙(style.css)은 0.3.109에서 들어감.
