# PLAN — 목소리 효과 (로드맵 6번 끼워 넣기)

시작 2026-10-06. 세션: `[DuckQ] 새기능: 목소리 효과`

## 하는 일
녹음 창에서 효과 하나를 고른다: **없음 · 마이크 · 전화 · 괴물 · 메아리**.
지금 녹음 흐름(0.3.106): 녹음 → 멈춤 → WAV로 바꿀 때 잡음 거르기(80Hz 자르기 + RNNoise) → 새 패드.
효과는 이 흐름 **잡음 거르기 바로 뒤**에 붙인다(깨끗한 소리에 효과를 걸어야 덜 지저분함).

## 효과 설계(초안, 브라우저 기본 기능만 — 새 라이브러리 없음)
| 효과 | 들리는 것 | 만드는 법 |
|---|---|---|
| 마이크 | 무대 마이크처럼 또렷·크게 | 저음 살짝 자르고 2~4kHz 올림 + 압축(소리 크기 고르게) |
| 전화 | 수화기 너머 목소리 | 300~3400Hz만 남김 + 살짝 찌그러뜨림 |
| 괴물 | 낮고 굵은 목소리 | 음높이 내림(속도 그대로) + 저음 보강 |
| 메아리 | 동굴·산 울림 | 지연 0.3초 되풀이(점점 작게) — 꼬리만큼 길이 늘어남 |

## 정한 것 (2026-10-06)
- 녹음과 별개. **아무 패드나 → 패드 설정 '목소리 바꾸기' → 들어 보고 고름 → 새 패드 '이름(효과)'로 저장**. 원본은 그대로.
- 녹음창은 잡음 거르기만 그대로.

## 끝 기준
1. 아이패드에서 아무 패드(녹음·파일)나 '목소리 바꾸기' → 효과를 눌러 미리 듣고 → 저장하면 옆에 새 패드가 생기고 그 목소리로 들린다.
2. 원본 패드와 예전 보드는 **전과 똑같이** 들린다.
3. 새 패드가 내보내기→가져오기 뒤에도 그대로(로그 `설정 담음/비교 … 전부 같음`).

## 진행 (2026-10-06)
- 만듦: 패드 설정 머리줄 '목소리' 단추 → 6효과(마이크·전화·괴물·메아리·로봇·다람쥐) + 원래 소리 미리 듣기 → '새 패드로 저장'. 트림 구간만, 최대 2분.
- PC 시험 통과: 6효과 소리 계산(괴물 음높이 0.68배·길이 그대로, 다람쥐 1.5배), 새 패드 생성·재생 준비, 내보내기 `설정 담음 … 전부 같음`.
- 남음: 아이패드에서 실제로 듣고 효과 세기 다듬기 · 버전 올리기(sw.js를 다른 창이 고치는 중이라 미룸) · 가져오기 비교 로그.

## 버린 방법
- 재생 때 실시간 효과(패드에서 켜고 끄기): 공연 중 끊김 위험, 페이드·잘라 담기와 엉킴.
- 원본 덮어쓰기: 되돌릴 수 없음.
- 녹음창에서만 고르기: 파일로 넣은 목소리엔 못 씀.
