## 0. 실제 쓰임 (설계 근거)
- **패드 대부분은 색이 없다.** 한 보드에서 색을 쓰는 건 1~4개. 그래서 색은 "찾기 강조", **중립 바탕의 품질이 화면 인상의 대부분**이다.
- 패드 색 선택지는 **없음 + 8색**. 기본값 = 없음.
- ~~색 없는 패드는 재생 중에 보드 색으로 켜진다~~ → **0.3.22: 색 없음 = "투명". 재생 중엔 밝은 무채색(다크 `#E4E8EF`, 화이트는 반대로 짙은 먹색 `#2E343D`)으로, 다른 색과 같은 규칙**(보드 색은 탭·테두리·배경에만). 소유자: 보드 색으로 켜지면 규칙이 없어 보임.
- 보드마다 색 하나(8색 중). 보드 색은 탭·판 테두리·뒷 배경 세 곳에 나온다.

## 1. 원칙
1. **UI는 중립색. 색은 사용자가 고른 곳(패드·보드)에서만.** 새 강조색을 만들지 않는다.
2. **상태는 한 가지 신호로만 표시하지 않는다.** 재생 중 = 밝아짐 + 커짐 + 그림자 + 진행 채움 + 레벨미터.
3. **순백·순흑 금지.** 글자 다크 `#ececee`·화이트 `#15181c`.
4. ~~테두리 선으로 상태를 표시하지 않는다~~ → **0.3.28: 재생 중만 겉 테두리**(패드와 2px 띄운 3px 선, 다크 흰색·화이트 먹색). 번짐 빛·크게 키우기 대신. 편집 모드의 '고름'은 ✓만(테두리 안 씀).
5. **재생 중 패드를 검정으로 뒤집지 않는다.** 색을 유지한 채 밝아진다.
6. **공연 중 오작동 방지:** 편집 버튼은 작고 어둡게, 재생 관련은 크고 밝게. 잠금 켜면 편집 버튼 비활성.
7. 애니메이션은 눌림·진행 채움·레벨미터뿐. 흐림(backdrop-filter)·큰 그림자·전환 효과 금지(구형 iPad 성능).

## 3. 패드 — 굵은 블록
공통: 모서리 20px, 그림자 없음, 테두리 선 없음. 라벨 굵기 900·자간 -0.03em·크기 19~28px(화면 따라)·2줄까지.
- 위쪽 왼쪽: **켜진 옵션만** 작은 둥근 칩 아이콘(페이드인·솔로·루프·다음재생). 꺼진 옵션은 표시 안 함.
- 위쪽 오른쪽: 패드 번호(01~) 작게. 재생 중엔 **레벨미터 막대 3개**(움직임)로 바뀜.
- 아래: 경과 `00:00` · (재생됨이면 `PLAYED` 칩) · 남은 `-00:00`. 고정폭 숫자.

| 상태 | 색 있는 패드 | 색 없는 패드 |
|---|---|---|
| 대기 | **어둡고 탁한 색**(색 38% + `#2b2f36`, 화이트는 45% + `#b9bec7`), 글자 `text` — 0.3.21 소유자 결정: 다크에서 재생 중 구분이 안 돼서 | 중립 블록(`text` 15%를 `bg1`에 섞음), 글자 `text` |
| **재생 중** | 원래 밝은 색(채도·밝기 올림) + **겉 테두리** + 더 밝은 같은 색이 **왼쪽에서 진행만큼 차오름**(58% 흰 섞음) · 1.035배 커짐 · 색 그림자(아래로 10px·26px 번짐) · 레벨미터 | 밝은 무채색 `#E4E8EF`로 켜짐(동일 효과) |
| 재생됨 | 대기와 같은 색 + `PLAYED` 칩(색은 안 바꿈) | 대기와 같음 + `PLAYED` 칩 |
- 눌림: 살짝 작아졌다 돌아옴(0.06초).
- 화이트에서 색 없는 패드는 흰 면 + 1px `line`.

## 4. 보드 색 세 곳 (모두 낮은 채도)
1. **보드 탭:** 점(●) + 선택 시 색 22% 배경 + 색 테두리.
2. **보드 판 테두리:** 2px, 보드 색 70% + 안쪽 은은한 빛(8%).
3. **뒷 배경:** 화면 위에서 퍼지는 방사 그라데이션, 보드 색 13%.
- 보드를 넘기면 세 곳이 함께 바뀜. 색 없는 패드의 재생 색도 함께 바뀜.

## 6. 구현 메모(1단계 코딩 세션에)
- CSS 변수 `--h`(패드 재생 색: 색 있으면 자기 색, 없으면 보드 색)·`--ink`·`--board`·`--p`(진행 %). 색 없음이면 `.none` 클래스.
- `color-mix()`는 iPadOS 16.2+ 사파리. **소유자 기기 OS 확인 필요.** 낮으면 미리 계산한 값으로 대체.
- 진행 채움은 `--p` 하나만 갱신(1초에 4번 정도면 충분). 레벨미터는 CSS 애니메이션(소리 크기와 연결은 2단계 "Animate With Audio").
- 확인할 것: 어두운 방·밝은 방에서 색 없는 패드와 재생 중 패드의 구분, 라벨 글자가 3m 거리에서 읽히는지.
- **알려진 약점:** 굵은 블록은 색을 많이 쓰는 보드에서 재생 중 구분이 상대적으로 약함(모두 밝은 면). 실기기에서 부족하면 "재생 중이 아닌 패드를 살짝 어둡게" 를 추가 후보로.
