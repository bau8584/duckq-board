# DESIGN — DuckQ Board (하드웨어 패드 톤)

> 화면 작업 전에 이 파일부터 읽는다. 조사 근거: `DESIGN-research.md` · 시안: `design/pad-mock.html` (같은 값을 쓴다).
> 우선순위: **① 가시성·실용성(무대, 어두운 곳, 구형 iPad) ② 그 방해 안 되는 선의 멋.**
> 방향 한 줄: **무대 뒤 계기판 + 하드웨어 패드.** 껍데기는 조용한 무광, 색은 패드와 보드 표식에만.

## 1. 원칙
1. **UI는 흑백, 색은 사용자가 고른 곳에서만.** 새 강조색을 만들지 않는다.
2. **상태는 그림자만으로 표시하지 않는다.** 재생 중 = 색 점등 + 밝은 테두리 + 진행 바 + 글자색 반전(여럿).
3. **순백·순흑 금지.** 글자 `#ececee`, 바탕 `#0c0d0f`. 어두운 곳에서 번짐 방지.
4. **깊이 = 면 밝기 단계 + 윗선 하이라이트.** 그림자는 보조. 눌림은 1px 내려가고 빛이 뒤집힌다.
5. **공연 중 오작동 방지:** 편집 관련 버튼은 작고 어둡게, 재생 관련은 크고 밝게. 잠금 켜면 편집 버튼 비활성.
6. **유리(반투명 흐림)는 설정 팝오버에만 약하게.** 패드·격자·하단 컨트롤에 쓰지 않는다(성능·대비).
7. 애니메이션은 눌림 0.06초와 진행 바뿐. 화려한 전환·튀는 효과 없음.

### 패드 8색 (고정, Okabe-Ito 기반 — 색각이상에서도 구분)
| SPEC 이름 | 값 | 재생 중 글자 |
|---|---|---|
| 회 | `#9AA0A8` | 검정(계산) |
| 자주 | `#CC79A7` | 검정 |
| 주황 | `#E69F00` | 검정 |
| 초록 | `#00A67C` | 검정 |
| 빨강 | `#E5622A` | 검정 |
| 파랑 | `#3E8FE0` | 검정/흰(계산) |
| 노랑 | `#F0E442` | 검정 |
| 하늘 | `#56B4E9` | 검정 |
- **자유 색 선택은 안 만든다**(중간 톤에서 글씨가 안 읽힘). 8색 고정. 글자색은 앱이 **흰/검 중 대비 큰 쪽을 JS로 계산**한다.
- 대기 색은 이 값을 어두운 바탕에 섞어(56%→42% 세로 그라데이션) 눌러 둔다. 색은 항상 보이고, 재생 중에만 100%로 켜진다.

## 3. 패드 상태 3가지
| 상태 | 모습 |
|---|---|
| 대기 | 눌린 색 면 + 윗선 하이라이트 + 아랫선 어둠. 글자 흰색(`text`). 위쪽 아이콘 5개는 꺼진 건 희미하게, 켜진 옵션만 밝게 |
| **재생 중** | 색 100% 점등 + **3px 밝은 테두리(lit)** + 바깥 빛 + 진행 바 + 글자 검정(대비 계산). 남은 시간 실시간 |
| 재생됨 | 대기와 같음 + 아래 가운데 `PLAYED` 글자. (색 변화 없음 — 실수로 재생 중과 헷갈리지 않게) |
- 눌림: 1px 내려가고 안쪽 그림자로 뒤집힘(0.06초).
- 패드 위 아이콘 5개(왼→오): 페이드인 · 솔로 · 루프 · 다음재생 · 페이드아웃.

## 4. 보드 색 (보드마다 8색 중 하나)
보드 색은 **세 곳**에 나온다 — 셋 다 낮은 채도로, 패드 색과 싸우지 않게:
1. **보드 탭:** 점(●) + 선택 시 색 22% 배경 + 색 테두리.
2. **보드 판 테두리:** 2px, 보드 색 70% + 안쪽 은은한 빛(8%).
3. **뒷 배경:** 화면 위쪽에서 퍼지는 방사 그라데이션, 보드 색 14%.
- 보드를 넘기면 이 셋이 함께 바뀐다(어느 보드인지 한눈에).

## 5. 레이아웃 (iPad 가로 기준, 11" = 1194×834 CSS px)
- 위: 좌 [설정][잠금] · 중앙 `전체 0:41:20 · 패드 24개` · 우 [일괄][복제][이동][삭제][＋추가](편집류, 작게).
- 보드 탭 줄(알약).
- 본판: 격자 6열×4행(Standard) + 오른쪽 MASTER 세로 슬라이더(64px).
- 아래: 좌 ⛶ · 가운데 마지막 재생 곡의 이름·진행·시간 · 우 [⏸][■][◣] **큰 버튼(84×54)**.
- 터치 크기: 최소 44px, 하단 컨트롤 54px. 패드는 화면 크기에 맞춰 늘어남.
- 크기 옵션(Compact/Standard/Large)은 열 수만 바꾼다(8/6/4 후보).

## 6. 글자
- 한글 시스템 글꼴 스택(`-apple-system, Apple SD Gothic Neo, Pretendard, Noto Sans KR`). 외부 글꼴 안 받음(공연 중 오프라인).
- 라벨: 굵기 700, 15~21px(화면 따라), 2줄까지, 단어 단위 줄바꿈.
- 시간: 11px 고정폭 숫자(`tabular-nums`), 반투명 흰색.
- 위계는 **크기와 굵기**로. 색으로 위계를 만들지 않는다.

## 7. AI 티 점검표 (시안 기준 자가진단)
| 항목 | 이 화면 |

| 그라데이션 | 패드 면 세로 미세(깊이용), 뒷 배경 방사 1개 — 장식 아님 |
| 이모지 | 없음(선 아이콘 SVG) |

## 8. 구현 메모(1단계 코딩 세션에)
- 색은 CSS 변수(`--h`, `--ink`, `--board`)로. 패드 색·보드 색은 저장 데이터에 "색 이름(8종 중)"으로만 저장.
- `color-mix()`는 iPadOS 16.2+ 사파리. 기기 OS가 더 낮으면 미리 계산한 값으로 대체 필요(**소유자 기기 OS 확인 필요**).
- 재생 중 표시는 그림자만이 아니라 테두리·진행 바·글자로도 나타낼 것.
- 확인할 것: 어두운 방·밝은 방에서 대기 색 8종이 구분되는지, 패드 글자 크기가 3m 거리에서 읽히는지.
