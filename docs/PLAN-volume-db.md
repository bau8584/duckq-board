# PLAN — 볼륨 막대를 귀 기준(dB)으로

## 왜 (2026-10-02, 10/1 연극 연습 로그 분석)
- 소유자: "0~100에서 아무리 낮춰도 별로 안 낮춰지는 느낌. 5나 15나 크게 다르지 않음."
- 실제: 볼륨 값은 진폭에 그대로 곱함(engine.js `setVolume` → gain = %/100). 100→50 = −6dB(살짝), 30 = −10dB(절반), 15 = −16dB, 5 = −26dB. 막대 대부분이 '거의 그대로' 구간이고 변화는 30 아래에 몰림.
- 로그상 볼륨 큐(◢ 5% 3초, 120% 3초)는 정확히 실행됨 → 값이 안 먹힌 게 아니라 **막대 모양 문제**.
- 120% 이상이 하나라도 있으면 리미터(engine.js `routeBoost`)를 거침 → 차이가 조금 더 좁게 느껴질 수 있음(작은 요인).

## 결정 (소유자 A안)
막대 위치 ↔ 값을 **귀 기준(dB)**으로 바꾼다. 화면 숫자 %와 저장 값(`p.vol`, 큐 `c.vol`·`duckO`)은 **그대로** — 기존 데이터 한 글자도 안 바뀜. 바뀌는 건 막대를 움직일 때의 간격뿐.
- 대상: 같은 막대를 쓰는 곳 전부 — 패드 설정 볼륨, 여러 패드 한꺼번에, 트랙 창, 큐 볼륨 막대(cue.js `volBar`), 나올 동안 다른 소리(`duckO`). 모두 `stepper(..., VOL_MAP)`(app.js `VOL_MAP`).
- MASTER 막대도 같은 문제인지 확인 후 함께할지 소유자에게 묻기.
- 막대 가운데·눈금이 귀로 '절반'에 가깝게. 0은 끝에서 완전 무음. 100% 위(키우기 ~300%)는 지금처럼 오른쪽.
- 스텝(+/−) 단추 간격도 dB에 맞출지(예: 3dB씩) 검토 — 단, 표시 숫자는 깔끔한 %로.

## 버린 방법
- B안(그대로 두고 "30 아래로 쓰세요" 안내): 관리자 손이 늘고 화면-동작 괴리가 남음.
- 저장 값을 dB로 바꾸기: 기존 사용자 데이터·내보내기 파일 변환이 필요해 위험.
