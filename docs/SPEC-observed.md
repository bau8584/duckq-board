| 격자 | 6열 × 4행 (Standard 크기), 세로 스크롤 |

→ 설계 근거: 긴 곡은 반드시 스트리밍(37분짜리를 메모리에 올리면 800MB). 효과음만 적재하면 총량 수십 MB. **300MB 상한은 넉넉함.**

## 1. 화면 구성

```
[⚙ 설정] [✎ 편집]        Board total 5:08:38 · 24 pads        [Bulk] [복제] [이동] [삭제] [+추가]
[ 큐어리스트 ] (보드 탭, 여러 개면 가로로)
┌──────┐┌──────┐┌──────┐┌──────┐┌──────┐┌──────┐        ┃MASTER
│◢ ↻ 🎧 → ◣│ ← 패드 상단: 페이드인·루프·솔로·다음재생·페이드아웃 아이콘(켜진 것만 밝게)    ┃ 슬라이더
│ 하우스 음악 │ ← 라벨(가운데, 2줄까지)                                              ┃ 100%
│00:00 PLAYED -13:54│ ← 경과 · 재생됨 표시 · 남은 시간                              ┃
└──────┘ … (6열 × 4행)
[⛶] [● ─────────── 하우스 음악 ─────────── -13:34]   [⏸ 전체일시정지] [■ 전체정지] [◣ 전체페이드]
```

- 재생 중 패드: 테두리 밝게 + 패드 안 진행 바 + 하단 스크러버에 이름·경과·남은 시간. 여러 개 재생 중이면 스크러버는 마지막 것.
- "PLAYED" 마커: 한 번 재생된 패드에 남음(공연 중 "이거 틀었나?" 방지). 설정에서 일괄 리셋.
- 좌하단 ⛶ = 전체화면/잠금 토글로 보임.

## 2. 패드 동작

| 동작 | 기본 | 설정으로 바뀜 |
|---|---|---|
| 탭 (정지 상태) | 재생 (트림 시작점부터) | — |
| 탭 (재생 중) | **페이드아웃 정지** (Global Fade Out 켜져 있으면 전역 1.9초, 아니면 트랙 설정값) | Repeated Pad Tap Restarts: 켜면 처음부터 다시 / Pad Tap Pause-Resume: 켜면 일시정지·재개 |
| 길게/편집 모드 탭 | 트랙 설정 열기 | — |
| 드래그(편집 모드) | 순서 바꾸기 | — |

## 3. 트랙 설정 (패드마다)

| 구역 | 항목 | 값 | 단계 |
|---|---|---|---|
| Appearance | Pad Label | 텍스트 | 1 |
| | 색 | 회·자주·주황·초록·빨강·파랑·노랑·하늘 8색 | 1 |
| | Pad Image | 사진 → 패드 배경 | **2 (Pro)** |
| | Animate With Audio | 소리 크기 따라 패드 밝기 | 1 |
| Adjustments | Volume | 0~100%, 슬라이더 + ±버튼 | 1 |
| | Pan | 좌우 | 1 (Web Audio StereoPanner) |
| | Trim | 시작·끝 지점(파형 화면) | 1 |
| Playback | Loop | 켬/끔 | 1 |
| | Solo | 켬/끔 — 이 패드 틀면 다른 것 정지 | 1 |
| | Plays Next Track | 끝나면 다음 패드 자동 재생 | 1 (Pro 자동화의 쉬운 판) |
| Fade In | 켬/끔 + Duration(초, 0.1 단위) | 예: 1.2초 | 1 |
| Fade Out | 켬/끔 + Duration | 예: 1.9초 | 1 |
| | Automations | 재생 상태 → 다른 패드 동작 | **2 (Pro)** |
| | Delete Track | | 1 |

## 4. 전역 설정

| 구역 | 항목 | 단계 |
|---|---|---|
| Default Track Settings | 새로 넣는 트랙의 기본값(위 표 전부) | 1 |
| Global Fade Out | Override Track Setting 켬/끔 + Duration → 모든 재생 중 트랙에 같은 페이드아웃 | 1 |
| Reset Played Tracks | PLAYED 마커 일괄 지우기 | 1 |
| Solo Tracks | 솔로 때 다른 트랙을 Stop All / Fade All / Individual(각자 페이드값) | 1 |
| Single Playback Mode | 켜면 모든 패드가 솔로 | 1 |
| Sound Visualiser | 새 트랙 기본 애니메이션 | 1 |
| Board Display | 패드 크기 Compact/Standard/Large · Page Board Scrolling(한 페이지씩 넘김, 오작동 방지) · 마스터 볼륨 표시 | 1 |
| Pad Playback | Repeated Pad Tap Restarts · Pad Tap Pause/Resume | 1 |
| Playback History | 재생 이력 CSV 내보내기 · 지우기 (로컬만, 서버 X) | 3 (있으면 좋음) |
| Audio Output | 출력 장치 선택 탭 | 웹은 iOS가 정함 → 안 만듦 |
| Transfer Help | 기기 간 이전 안내 | 3단계 쇼 파일 |

## 7. DuckQ가 다르게/추가로 하는 것 (ROADMAP §9)

- 패드·보드 **무제한** (24/4 상한 없음) — 이것만으로 "Pro 수준" 절반.
- 자동 저장·화면 꺼짐 방지·튕김 복귀·적재 검사 — 항상 켜짐, 설정 항목 아님.
- 편집 잠금 자물쇠 1탭(공연 중 드래그·설정 오작동 방지) — 앱의 ⛶·Page Board Scrolling이 하던 역할.
- 출력 장치 선택·애플뮤직 가져오기·백그라운드 재생 — 안 함(웹 한계, 알고 감).
